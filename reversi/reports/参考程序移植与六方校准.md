# 三个新增参考 bot 与六 bot 循环赛

按用户要求，新增 Wugengxian C++ 移植版、Ultimate_Reversi 修复版和 programmingLearner，与既有 SiriusAlpha、skip2004、piggy2 两两对战。每对 16 局，双方各执黑 8 局，共 15 对、240 局。旧三者之间的 48 局按原始字节与哈希直接复用，新增 192 局；标准开局，随机种子仅作元数据，重复局不等同于独立随机开局。

原生 C++ 裁判、运行器与既有三个 bot 二进制不变。外层动作限制继续为 2.5 秒，四桌并行。三个新增版本内部搜索预算均为约 900 ms；因此移植版/修复版不冒充原作者在其他时限下的棋力。没有重新训练或替换外部学习参数。

显示名称：Wugengxian → Aster，Ultimate_Reversi → Onyx，programmingLearner → Lumen，skip2004 → Flint，piggy2 → Vex，siriusalpha → Sirius。仅更改页面显示，冻结标识、程序及历史记录不变。见 `naming-verification.json`。

## Wugengxian C++ 移植版

来源：[Wugengxian/---ai](https://github.com/Wugengxian/---ai)，原始提交 `f276b1f0c03e9fbf8af46b6a44fbddd19ff6d0a2`。`wugengxian.cpp` 实现原模式评估、位棋盘、对称变换、快速排序评估、PVS 和置换表。仓库全部 13 阶段模式数据保留为 IEEE float64，`wugengxian-patterns.bin` 只是原 JSON 的无损二进制转换，包含原开局库。

兼容修正：Python 无限精度乘法中用于模式索引的中间结果使用 C++ 128 位无符号整数，负索引按 Python 规则换算；取反右移明确保留 Python 符号扩展含义。JSON 开局库字符串键转换为整数；终局平局返回 0；迭代搜索保留最后完成层的合法着法。原模式评估与排序评估不变。

对照原 Python 代码，122 个真实局面的模式评估、排序评估、稳定子、前沿子、合法着法和对称变换一致；1118 个合法落子的翻子结果一致；12 个局面的固定深度 2 搜索分值及最佳着法一致。见 `port-verification.json`。此前审计报告关于原跳步判断的误读已经更正：其 get_move 参数顺序与调用变量名相反，原跳步判断是正确的。

## Ultimate_Reversi 修复版

来源：[Walleclipse/Ultimate_Reversi](https://github.com/Walleclipse/Ultimate_Reversi)，提交 `1f40c0f1cf3b9422cf67f9a787dde9cb9b6dc40b`。提取原困难 AI 的棋盘操作、手工评估、alpha-beta 和置换表，保留作者系数，去掉 EasyX 图形/音乐/联网/菜单依赖；生成范围及补丁在 `prepare.py` 可复查。

修复终局函数重复统计自身而完全不统计对手的错误，按当前搜索方计算胜负；补齐原先未初始化的部分 Zobrist 表，使用固定种子初始化所有 64 格；置换表保存上下界时与进入节点时的 alpha/beta 比较，覆盖终局数值范围；迭代从浅层开始，时间不足时保留已完成的着法；无着法时回复 PASS。

已验证全白棋盘黑方判负、白方判胜、32:32 平局、双颜色视角、完整哈希初始化及 PASS。见 `ultimate_probe.cpp` 和 `port-verification.json`。

## programmingLearner

来源：[programmingLearner/Reversi](https://github.com/programmingLearner/Reversi)，提交 `53dd37ece175fb85c6128ca4dd777a252b3c142e`，保留原仓库 MIT 许可证。适配原 `AI.cpp`、`reverse.cpp`、`judge_end.cpp`，仅将检查副本从旧编码转换为 UTF-8。原评估函数和系数保留，新增原生 JSONL 输入输出与棋盘坐标转换。

加入截止时间检查；在原默认搜索深度 8 之前逐层完成较浅搜索，余时允许时按原阈值执行残局精确搜索；递归调用的连续跳步计数按作用域保存和恢复，防止兄弟分支污染。对外无着法时直接回复 PASS。

三个新增版本均通过原生协议开局/PASS 检查，并各执黑白与简单启发式 bot 完成对局验收：6 局，0 故障。验收只作为接入检查，不计入本次六 bot 的 240 局成绩。
