# 黑白棋参考 bot 校准

8 个 bot、28 对，每对 16 局，双方各执黑 8 局，共 448 局。每个 bot 共 112 局，执黑、执白各 56 局。胜/和/负计 2/1/0。
统一每步截止 2.5 秒，首步同限，4 局并行，标准开局。确定性程序可能重复棋谱；16 次对局不等于 16 个独立开局。
原有 336 局逐字节保留，原执行器、原程序与桥接器哈希均未改变；新增 SiriusAlpha 对所有原有 7 个 bot 各 16 局，共 112 局。补赛接入实时状态输出时，使用由 Ataxx runner_live.cpp 适配的 C++ 执行器，执行器哈希和切换前记录另行封存；全部棋谱均经原 C++ 裁判逐帧复核。合并后全部 28 对均已完成。
SiriusAlpha 的 Botzone v48 源码未改动。作者 v2.4 发布包包含 pattern.dat 与预测表；公开 fork 的旧格式 pattern.dat 与官方发布包的全部浮点权重字节完全相同。已适配数据路径并验证加载和实际对战。尚不能确认这些公开数据与历史榜单权重完全相同，1876.18 仅作来源榜单分数。
