# Ataxx 静态开发观察与正式赛归档

[开发与Astra接续观察页](index.html) · [正式赛540局](tournament.html) · [Markdown报告目录](reports/README.md)

沿用既有观察布局，六位限时开发各页保留版本、工作摘要、重要事件、用量费用、自测/验收/追加测试记录。第七个模型页是Astra接续阶段，其固定时间轴为接续开始至最后停止的全部跨度，明确区分暂停与停止空档，不套用180+20分钟。拖动角色或用方向键、Home、End、PageUp/PageDown回看；不会因拖动改变轴长。

开发页面没有开发测试棋盘历史或自动回放。正式赛页面有全部540局结果、排名、相互战绩和既有32次颜色修正Elo；每局完整棋谱独立位于matches目录，只有点击回放时才加载。

纯静态HTML/CSS/JavaScript，无本地API、localhost或外部脚本CDN依赖。可部署到任意静态HTTP子目录；浏览器直接file://打开时可能限制JSON fetch。报告只有Markdown，没有HTML报告版。

不发布参赛源码、二进制、权重、训练输入、特征缓存、私有CLI或凭证。版本快照、验证范围、未知时刻及费用缺失都有明确说明，不把文件存在等同于运行正确或棋力更强。

完整公开文件清单见 [FILES.md](FILES.md)，包含相对路径、字节数及 SHA-256；不含私有归档脚本或原始开发输入。
